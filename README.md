# دفتر المواعيد

تطبيق أندرويد للملاحظات واشتراكات الناس مع إشعار في موعد الانتهاء.

## طريقة بناء الـ APK
1. أنشئ مستودع جديد على GitHub وارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow** (يعمل تلقائيًا أيضًا عند كل رفع).
3. بعد 5 إلى 8 دقائق افتح التشغيل الناجح ونزّل **daftar-apk** من قسم Artifacts.
4. فك الضغط وثبّت `app-debug.apk` على الهاتف.
